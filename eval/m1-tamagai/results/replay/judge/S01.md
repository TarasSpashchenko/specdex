## Answer A

FR-68 ("Linking and consent states") says a parent becomes the device's linked parent by completing the consent method once (FR-86). After that, our servers keep only the linked-parent record. It realizes UJ-10.

The state table has four rows: Unlinked, Linked (on-device tier), Linked with consent (server tier), and Linked without consent (server tier). Its columns are the events Link or consent, Revoke consent, Unlink, Delete everything, and Refund.

- **Revoke consent:** only the "Linked with consent" row responds. It becomes "Linked without consent" and server talk stops.
- **Unlink:** from any linked state, the device becomes unlinked and loosened limits return to defaults.
- **Delete everything:** on-device family data is deleted and model files stay. For linked states, record deletion is "requested, shown as not yet accepted or accepted, never as completed".
- **Refund:** the result is Basic mode. Server talk stops, and the device stays linked. The table's Unlinked row also shows Basic mode.

The rules under the table cover timing and scope:
- "Stops" means before the next voice turn and within 60 s. After a refund, server talk stops within 24 hours (FR-83).
- Web unlink or record deletion reaches the device at its next successful link check. Checks occur at least every 30 days while online, with no guarantee offline.
- A web record deletion unlinks the device but doesn't remotely erase the child's pet.
- "Loosened limits return to defaults" means every setting in FR-69's "Go beyond the SB 1119 defaults" row. Settings within the defaults are kept.
- On the on-device tier, the linking notice says no child data is collected.

## Answer B

FR-68 ("Linking and consent states") is a current requirement in the PRD. A parent becomes the device's linked parent by completing the consent method once (FR-86), after which servers keep only the linked-parent record. It realizes UJ-10.

The state table has four states (Unlinked, Linked on-device tier, Linked with consent, Linked without consent) and five events (Link or consent, Revoke consent, Unlink, Delete everything, Refund):

| From \ event | Link or consent | Revoke consent | Unlink | Delete everything | Refund |
|---|---|---|---|---|---|
| Unlinked | Linked (server tier: linked with consent) | — | — | Family's on-device data deleted; model files stay (FR-71) | Basic mode |
| Linked (on-device tier) | — | — | Unlinked; loosened limits return to defaults | Unlinked; on-device data deleted, model files stay; record deletion requested, shown as not yet accepted or accepted, never as completed (FR-71) | Basic mode; still linked |
| Linked with consent (server tier) | — | Linked without consent; server talk stops | Unlinked; server talk stops; loosened limits return to defaults | Same as the row above (unlinked, on-device data deleted, record deletion requested) | Basic mode; server talk stops; still linked |
| Linked without consent (server tier) | Linked with consent (no new purchase) | — | Unlinked; loosened limits return to defaults | Same as the row above (unlinked, on-device data deleted, record deletion requested) | Basic mode; still linked |

Other consequences:
- "Stops" means before the next voice turn and within 60 s. After a refund it means within 24 hours (FR-83).
- On the on-device tier, the linking notice says that no child data is collected.
- A web unlink or record deletion reaches the device at its next successful link check, which happens at least every 30 days while online. Offline delivery has no 30-day guarantee. A web record deletion unlinks the device but does not remotely erase the child's pet.
- "Loosened limits return to defaults" means every setting in FR-69's "Go beyond the SB 1119 defaults" row returns to its default.
