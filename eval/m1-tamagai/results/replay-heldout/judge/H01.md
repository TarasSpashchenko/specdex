**Question:** If an adult erases something the pet has learned, where must it disappear, and does the pet lose abilities it already earned?

**Gold answer:** Only a parent can delete a word card; deletion removes the word from vocabulary, lines, dreams and diary. The taught-word count drops, but reached ladder steps remain reached, and Pip says nothing about the deletion.

## Answer A

When a parent deletes a taught word's card, the word must disappear everywhere it appears: the vocabulary, Pip's lines, dreams and the diary. Only the parent can do this. The child can't delete a card, but can teach the same word again. Pip does not lose abilities it already earned. The taught-word count drops, but ladder steps already reached stay reached, and Pip says nothing about the deletion. The architecture notes implement this by storing the maximum step separately from the word list.
