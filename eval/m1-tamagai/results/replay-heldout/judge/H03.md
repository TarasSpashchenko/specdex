# Task H03

**Question:** How should we arrange and style the two answers when asking an adult to approve something, so saying no is as easy as saying yes?

**Gold answer:** Use the same size, style and weight, with two tonal buttons rather than a filled button beside a text button. The declining or keeping option comes first (left, first in focus order, or on top when stacked); segmented choices preselect the more private option, with the detailed layout and styling marked as assumptions.

## Answer A

Place the answers side by side, with the declining option (“No” or “Not now”) on the left and first in keyboard focus order; when space or large text requires stacking, put it on top. Give both the same size, tonal style and visual weight—never a filled approval button beside a text-only refusal. Use neutral wording without guilt, loss framing or urgency, and preselect only the more private option where a standing choice needs a default.

## Answer B

Give both answers equal prominence, size, style, and visual weight; never pair a filled “Yes” with a text-only “No.” The proposed action layout—marked as a UX assumption—uses two tonal buttons 12 dp apart, with “No” or “Not now” first: leftmost, first in focus order, or on top when stacked. Use neutral wording without guilt or loss framing, and preselect the more private option. For selectable choices, the proposed alternative is two joined tonal segments, with a check and 2 dp border marking the selection.

## Answer C

Use the spec's "Equal choice pair" for every adult approval (buy, consent, link, delete, skip/allow). Make both answers the same size, the same tonal style and the same weight. Never put a filled button next to a text button, and use no danger colour. Put the declining or keeping option first: on the left, first in focus order, and on top when the buttons stack. The buttons stack in the same order at narrow widths or large text sizes. Where a setting is preselected, preselect the more private option, such as "No" for counters. The copy should be neutral, with no loss framing, urgency or countdown. This follows from the regulatory rule of equal buttons and no dark patterns (SB 1119, ICO standard 13) and from NFR-18.

The left/right order of "Not now" differs between the consent and offer flows. The validation report flagged this as an inconsistency.

## Answer D

Use an "Equal choice pair": two buttons of the same size, style and weight, both tonal. Put the declining or keeping option first, so it sits on the left, first in focus order, and on top when stacked. Examples are "Not now / Buy", "No / Yes" and "Keep / Delete". Never put a filled button next to a text button, and use no danger color. Neither option is framed as a loss, and where the choice is a setting, the more private option is preselected. The pair layout, its order and the "no danger color" rule are marked `[ASSUMPTION]` in the design spec. The equal-prominence rule itself comes from the PRD requirement NFR-18.
